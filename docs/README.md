# YAMuino Documentation

This directory contains the project documentation intended for publication with the repository.

- [MANUAL.md](MANUAL.md) - complete user, installation and operation manual.
- [WIRING.md](WIRING.md) - electrical connections and pin assignments.
- [PROTOCOL.md](PROTOCOL.md) - Yamaha System Control and NEC protocol notes.
- [REMOTE_MAPPING.md](REMOTE_MAPPING.md) - supported Yamaha and TVIX remote commands.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md) - diagnosis of common problems.
- [DEVELOPMENT.md](DEVELOPMENT.md) - build, debug and extension notes.
- [GITHUB_DESKTOP.md](GITHUB_DESKTOP.md) - local repository and publication procedure.
- [THIRD_PARTY.md](THIRD_PARTY.md) - external dependencies and reference-material notes.
